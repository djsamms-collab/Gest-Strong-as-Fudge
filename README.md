# Get Strong As Fudge PWA

This version is meant to be hosted once, then installed on an iPhone Home Screen.

After installation:
- Opens without a computer
- Works offline
- Saves main lift and accessory data locally
- Supports movement-specific accessory substitutions
- Lets you update training maxes

Files:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/

Upload the entire folder to any static HTTPS host. Then open the site in Safari and choose Share → Add to Home Screen.
